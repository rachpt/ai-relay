# 0013：原生控件视觉统一与输入框边界

- 日期：2026-10-19
- 状态：已接受；其中6 DIP页内圆角值于2026-10-29由[ADR0019](0019-fluent-presentation-tokens.md)取代，以下保留原始决策与验证
- 关联：需求8.1；补充ADR0006，不改变原生GUI或高对比度路线

## 背景

逐项描边的分段按钮、浅深不一致的下拉/表格和灰硬Edit边框使界面缺少层级。仅裁剪原生Edit无法得到完整圆角，且可能破坏客户区、caret/IME和重绘。目标是改善组件，而不是用完全自绘界面替换Windows控件。

## 决策

- 继续使用原生 Button、Tab、ComboBox、ListView/Header、Edit 和日期控件；仅展示层子类或owner/custom draw改变外观。选择、值、键盘、通知和可访问性仍由原生控件负责。
- 浅深主题共享柔和中性色与强调色；主要动作实心、次要动作中性、危险动作淡红，焦点独立可见。Tab分段使用整体轨道，不改变原生item矩形或已有布局坐标。
- 闭合下拉、switch及表头在浅深均统一绘制。ListView在两应用主题使用公开的无主题绘制回退，让custom-draw行背景可靠生效；不使用未文档暗色API。高对比度卸载这些绘制并恢复系统主题与颜色。
- 有边框Edit在创建时设置 `WS_EX_CLIENTEDGE`，取得真实非客户区；该样式不是主题切换时添加/删除。`input_frame` 通过实际窗口/客户区坐标限制补画，先排除整个客户区，只绘制矩形边框；无边框空间时不臆造客户区边线，不使用window region或圆角裁剪。
- 保留密码、只读、多行和滚动条原生行为。原生绘制先处理，外框随后补画；需要同步回调的子类持有可复制的presentation或保留Rc，打印使用SaveDC/RestoreDC守卫。网络/磁盘/日志路径不参与绘制。
- 不增加依赖、Cargo feature、浏览器运行时或字体/图像联网下载。现有6 DIP控件圆角及内嵌导航图标继续使用。

## 备选方案

- 只改Palette：能减轻边线，但不能改善分段、主次动作及输入框状态。
- 裁剪Edit圆角或覆绘客户区：不采用，优先保护真实输入/选区/IME边界。
- WinUI/WebView/完整自绘输入：本批不采用，部署、无障碍和输入实现成本不符合当前需求。

## 影响与验证

Edit可用客户区比原始无非客户区夹具略小；现有28/30 DIP高度下通过原生输入、草稿/选区、密码空值掩码和真实应用打印像素回归。主题流程不重置输入或配置。输入框保持矩形，系统菜单/日期编辑/日历等仍可保留系统外观，不宣传完整Fluent/WinUI替代。

347项全量串行测试、严格Clippy及Debug/静态CRT Release通过；96 DPI现代界面四页双主题双尺寸矩阵通过，已执行物理残影与GDI项目通过但部分截图被遮挡。真实高对比度、多屏、高DPI、读屏与IME组合期间切换仍待验收，详见[开发记录](../development/2026-10-19-01-native-ui-polish.md)。
