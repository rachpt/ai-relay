# 0005：原生分页与有界日志后台

- 日期：2026-10-17
- 状态：已接受（增量实现）
- 关联：需求8.1/8.4，UI-DESIGN

使用Windows Common Controls原生Tab拆分概览、统计、日志、设置，不增加GUI框架，仅启用现有windows-sys的Controls feature。保留控件实例与草稿，隐藏页退出焦点导航且停止无必要绘制；统计暂展示真实会话数据，不造历史图。

日志不引入额外依赖：类型化事件经过有界队列，由专有worker更新有界内存缓存及写JSONL。网络只try_log；满队列或关闭时丢失可见。自由文本/原始URL/错误不进入事件；未知endpoint脱敏，不接收Key、query、body。请求终态guard在成功/错误/取消只尝试投递一次，健康不记访问日志；这不是保证磁盘恰好一次交付。

日志服务在后台controller创建并使用，命令有限等待；超时不意味取消，不能自动重试删除。当前或历史文件尾读最多256KiB/2000行，严格应用文件名、重解析点/硬链接检查及Windows共享打开。清理走预览和确认，worker协调关闭/重开，不从UI线程直接删除。原配置目录未确定前不偷偷创建标准路径日志。

配置新增file_enabled与retention_days，serde默认兼容已有配置。日志设置即时应用暂未落盘，须正常保存；页面明确标注，不能回填覆盖未保存网络输入。

未完成：文件跟随/向前分页、完整分类/时间筛选与排序、打开目录快捷入口、日志设置迁入完整分类页、物理键盘/DPI、多维统计历史。这些目标未因本ADR删减。
