# 0008：历史读写隔离、日历报表与窗口偏好

- 日期：2026-10-18
- 状态：已接受；补充ADR0007，需求v1.6

## 背景与决策

此前history owner串行完成聚合和记录写入，10万条三级分组/Token排序可运行十余秒，阻塞写入队列并造成已完成请求元数据丢失。采用固定reader actor读取WAL一致快照，writer只写入及控制，不在writer中等待读查询。主库只读、TEMP表允许用于有界排序/聚合；最多4个已接纳读任务、60秒端到端预算，SQLite interrupt和逐行取消，Drop不无限join。查询前短barrier保证此前入队记录可见。全量CSV同一事务逐行写出，不把分页当全量，不整表收集到内存。

记录条数缓存通过data_version检测外部改动，避免每次写入都扫描10万条保留索引。读快照可延迟WAL截断，policy明确返回checkpoint Busy；迁移/关闭的成功证明必须等待reader停止和writer checkpoint。操作系统文件I/O不能即时取消时不假称文件完整。

加入chrono 0.4（clock/std）处理历史时间的UTC/Local转换及日历边界，不使用当前偏移替代历史DST。无额外运行时；任意IANA时区和多时区并列不在当前实现中。schema v1→v2事务创建别名表，不改变HMAC身份；未知版本拒绝。

凭据别名仅标注本地HMAC ID，不改变聚合身份，拒绝常见密钥格式；导出别名仍有隐私风险，需明确确认。历史策略只在独立确认入口修改，普通设置草稿若携带旧策略，在停止代理前拒绝，避免旧草稿回写触发不可逆清理。

## 代理与窗口边界

请求体不预读：wrapper按原有背压轮询，最多64KiB临时观察，只有真实EOS及完整合法JSON才发布顶层model。重复字段/非字符串/取消/编码不支持保持未知；正文不入库。指标只计atomic，无网络路径I/O；会话时长含停止间隔，流量为HTTP正文交接或CONNECT成功写入，不是计费字节。

窗口偏好存实际数据目录window.json，与主配置分离，后台有界读取及原子替换；UI只做Win32捕获/工作区校正。加载失败不缓存成功scope，允许重试；保存按drag结束/退出防抖，不在每次resize同步写盘。关闭到托盘与退出依据已保存设置。

## 验证与限制

10万条高基数查询/全量导出期间各1500条、2ms写入回归由旧1024入队/476丢弃改为1500/0。查询仍约11–17秒，未宣称加速或完成完整性能验收。实机200%DPI验证几何物理坐标与落盘/重启一致，不能替代多屏、读屏、真实关机和24小时长稳。
