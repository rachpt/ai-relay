## DPAPI和Windows集成

当前用户DPAPI保护凭据，密文放config.toml的版本化protected_secrets，而非独立secrets.dat。单文件原子替换消除配置/秘密两文件提交不一致；明文和密文冲突拒绝、篡改失败不降级，临时秘密缓冲尽力清零，不能宣称运行时String或分页全无残留。导出默认清除两类秘密及依赖开关。

自启采用windows 0.62公开COM ShellLink，复用系统组件无需新运行时。标记和目标都校验，仅当前用户Startup；实际状态与配置不一致时显示部分成功，不伪装跨系统/文件原子事务。

GUI子系统+父控制台附着和重定向保留，CLI分类退出码及受限IPC。启动子进程使用绝对EXE和参数数组，不走shell。后台启动失败可保留主窗口诊断。

## 历史数据

rusqlite 0.38 bundled静态编译SQLite，不要求数据库服务。hmac/sha2/getrandom用于本地随机身份和HMAC-SHA256凭据ID，身份文件Windows DPAPI保护。构建增加C编译需求，已有Build Tools可用；代码体积增加需实测。

仅存请求元数据和实际usage，不存原Key、任意URL查询、正文。来源为TCPpeer；客户端/实际上游凭据来源分开哈希。模型响应取得，请求模型暂未知。记录通过有界非阻塞队列，拒绝/错误/取消有终态，健康排除；队列或磁盘错误明确计数。

SQLite owner线程事务写入与查询，UI/controller查询专用线程隔离网络；参数绑定及白名单分组，最多100明细/三级分组/366日趋势。默认90天10万条，保留期和记录上限不保证磁盘字节严格封顶。查询当前逐行聚合，复杂索引/排序/时区和策略GUI待后续优化。

## 保存应用与迁移

保存检查外部baseline，运行中受控停止/保存/启动；启动失败明确状态，用户确认回滚。LAN确认绑定目录/已保存配置，仅该次操作，CLI和自动启动不复用。

迁移先停止代理，预览源目标和覆盖策略，SQLite VACUUM INTO制作一致快照并保留HMAC身份，确认源worker关闭后发布。目标有独立历史拒绝自动合并；已有有效配置原子备份。源配置、数据库和日志不删除，日志默认不迁移。

发布使用不覆盖移动，切换便携标记并更新原已启用自启；失败尽力撤销本批发布、修复自启与标记，保留暂存副本并报告回退失败。不是跨文件/系统崩溃原子事务；发生中断应按报告检查恢复目录，不能宣称任何断电都能自动恢复。

本地mock、临时目录覆盖DPAPI/配置冲突/快照回退/协议/历史与GUI、CLI。自启COM测试只操作临时目录，不改真实Startup。发布使用crt-static和PE导入检查，但不代替干净系统、依赖许可证、签名及24小时长稳。UTC历史页、当前页CSV、凭据ID筛选是真实能力，别名、完整时区/月报/排序仍未完成。
