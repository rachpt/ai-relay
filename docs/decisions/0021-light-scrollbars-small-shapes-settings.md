# 0021：浅深滚动条、小图形抗锯齿与类型化设置输入

- 日期：2026-10-31
- 状态：已接受
- 关联：需求 v1.8 的6.5、8.1、8.3、8.4；补充ADR0013／0019／0020；仅取代ADR0014第3／7条及ADR0017第1／4条的Light-native主题范围，其他安全与交互约束不变。

## 背景

用户反馈浅色统计表横纵滚动条仍是经典粗条，开关和运行图标锯齿明显，Release“关于”固定写开发预览；设置缺少Key显隐，短字段布局和数字校验不一致。原实现已经有深色滚动条跟踪、Report局部合成及原生输入控件，不需要换GUI框架或重做内容层。

## 决策

1. 已识别的Edit、Report及页面宿主在Light／Dark共用窄胶囊展示与公开API鼠标适配，色彩来自当前Palette。保留完整原生命中区、range/page、正文、选区、键盘／滚轮、单元格复制与32位位置。Contrast仍卸载自有跟踪及合成位、恢复系统行为；未知类及资源失败可读原生降级。Report局部COMPOSITED所有权、同步重入、generation／capture取消和禁绘守卫沿用既有实现，不扩大到整窗。
2. 新增只用于小图形的CPU 4×4覆盖采样及32-bit DIB呈现，应用于38×20 DIP开关、16 DIP状态图标及Key眼睛图标；正文仍由原生字体绘制。单边4096像素、65,536像素总量、64图元、32顶点及8M采样评估硬上限，内存可失败分配、无全局缓存。调用者提供已知纯色背景，不读取桌面；尊重借用DC映射／复杂clip。失败保留GDI形状或中文按钮回退；高对比度保留原生开关和系统色图标。
3. Key只通过EM_SETPASSWORDCHAR显隐，不复制／替换秘密正文、不写存储、不改代理状态。中文原生按钮保留键盘、可访问caption和禁用状态。离开上游分类／设置主Tab、隐藏／最小化／关闭窗口、populate／放弃草稿和禁用操作时重掩码；切换不丢UTF-16选区。不得据此声称秘密已从进程内存擦除，也不能防止用户主动截屏／共享明文。
4. 数字字段共用元数据生成范围提示、输入长度与保存校验；字符／IME字符／替换／粘贴拒绝非ASCII数字或超长结果，整次拒绝而非截断。允许空值及范围外草稿继续编辑，保存必须拒绝，不静默clamp。端口1–65535；网络值维持既有u32边界，两个idle允许0，不能因UI美化擅自缩小配置合法域。剪贴板只读且有界，不为测试覆盖用户剪贴板。
5. 保留六分类、控件ID和显式保存／迁移／风险确认，不为了密度强合并安全边界。URL／Key／文本列表伸展，IP／port／固定选项下拉按类型限宽；网络内容宽680 DIP起两列，否则单列，数字框148 DIP；688 DIP以下动作换两行。原生Tab顺序按可见表单排列。虚拟高度基于最终内容宽、实际原生滚动条宽及当前分类计算，不留隐藏分类尾部或覆盖固定状态栏。
6. 关于版本使用Cargo包版本，以编译配置区分Debug开发构建／Release构建；Release主标题去掉“开发版”。编译profile不等于正式发行验收，README／STATUS继续明确产品成熟度。

## 不采用的方案

- 只替换浅色静止截图，拖动时继续系统粗条：不符合交互目标。
- 全窗缩放栅格／把文本一起超采样：破坏字体和输入边界、额外消耗资源。
- ES_NUMBER作为唯一防线：原生粘贴可绕过字符限制，也不能说明合法范围。
- 修改超时配置上限、合并全部分类或引入新的配置schema：不属于本次用户界面修复。
- Electron／WebView／WinUI运行时、未文档暗色API或联网图标：无必要，也不符合既有部署边界。

## 验证边界

普通native／离屏测试可证明范围、状态、DC／GDI及混合边缘像素，但不等于真实高DPI、多屏、Win10／11差异、读屏或连续刷新视觉验收。按住未释放物理采样拒绝遮挡，失败／跳过不能作为通过；Release构建、版本／PE检查与GUI分别记录。实际命令、首轮失败及结果见[本批记录](../development/2026-10-31-01-ui-input-scroll-polish.md)。
