# 0004：单实例信任边界与被动用量统计

- 日期：2026-10-17
- 状态：已接受（当前增量实现）
- 关联：需求第 4.3、8.5、9 节

## 决策

单实例采用当前用户 SID + session 标识的 Mutex 和命名管道。受保护 DACL 限当前用户，拒绝远端管道连接，双方核验用户/session，检查 Mutex 所有者。协议版本化、长度上限 4096 字节，读取限时 2 秒、事务总限时 40 秒，不发送密钥。同用户恶意进程仍在信任边界内，不宣称签名级应用认证。命名抢占安全失败，不退化为不受保护 IPC。

新增 serde_json 1：用于有界 IPC 协议和 Provider usage 解析，编译进 EXE，不引入外部运行时。

Token 统计被动观察现有响应帧，不改变请求、响应或背压。JSON 缓冲最多256 KiB，SSE行/事件64 KiB，超限只停观察。临时正文仅供解析不进入报告、磁盘或日志；报告只保留用量、受限模型标识和完整度/错误状态。

OpenAI 缓存和推理是子项不能重复相加；Anthropic cache 字段单列，快照覆盖不相加。未知保留 None。响应结束/异常/取消恰好记录一次；上游调用前的本地拒绝和健康请求不进入 usage 统计。头前失败记录未知，截断可保留已观察计数但必须附状态。

统计采用短临界区、有界128组聚合和溢出桶；后台每秒生成界面文本，经独立容量1通道传给GUI，不争用操作结果队列。协议类型不是实际供应商身份。当前只做进程会话，跨启停保留、退出清零，不隐式创建历史账本或价格数据库。

## 影响与未决事项

单实例避免正常多开写入竞争，但不能防御同用户恶意文件竞争。CLI仍是控制台子系统，start/restart和完整退出码后续完成。跨用户/提权组合尚需验收。

被动统计无法保证流式Provider返回usage，也无法覆盖压缩或超限正文；不通过修改请求强制索取，也不伪造估算。持久化、实际Provider分组、日期报表、导出和费用估算均须另行设计。观察增加有界CPU/内存成本，尚未进行性能/长稳测量。
