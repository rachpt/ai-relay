# 0010：SVG 设计源与内嵌原生导航图标

- 日期：2026-10-18
- 状态：已接受
- 关联：需求 8.1、12；ADR0001、0006；开发记录 2026-10-18-18

## 背景

导航原来以 Unicode 符号充当图标，字重、基线、字体回退和语义不一致。需要改进浅深主题及 DPI 下的图标质量，但不引入浏览器引擎或另行安装的运行时。原生 Tab 继续负责键盘、选择、命中和可访问名称。

## 决策

- 四个导航图标采用项目原创 SVG 设计源，保存在 `assets/navigation/`。
- 开发期由 `tools/generate-navigation-icons.ps1` 使用 Windows 自带 .NET Framework/System.Drawing 离线生成六档 alpha 遮罩；生成物纳入版本控制，正常 Cargo 构建不执行脚本。
- 脚本只接受明确、受限的 SVG XML/几何子集，拒绝脚本、外部资源、DTD、实体及不支持内容；不宣称支持任意 SVG。格式和精确命令见资源目录 README。
- 运行期通过 `include_bytes!` 内嵌遮罩，用预乘 BGRA DIB 和公开 `msimg32!AlphaBlend` 绘制。按 DPI 和主题颜色有界缓存，不读取磁盘，不在每次 paint 中逐像素调用 GDI。
- 图标独立于中文标签，高对比度保持原生纯文本；资源或空间不足时降级为文字。不修改 Tab 输入/通知/可访问性契约。
- 不增加 Cargo 依赖、DLL 分发或最低 Windows 构建号要求。只新增对 Windows 10/11 自带 msimg32.dll 的链接。

## 备选方案

- Direct2D 运行时 SVG：可以扩展矢量绘制，但需设备、文档、缓存、丢失恢复和旧系统兼容管理；当前四张固定图标不需要这一路线。
- 通用 Rust SVG 渲染库：增加依赖、二进制体积及许可证审计，不适用于当前有限需求。
- 图标字体：受系统字体可用性和字形差异影响，继续保留当前问题。

## 影响与风险

- SVG 是可编辑设计源，不是运行时用户输入格式；修改后必须重新生成并提交 `.mask`。
- 常用 DPI 使用 18/27/36/48/72/144 像素帧，中间 DPI 仅缓存缺失时采样；栅格图仍非任意缩放的实时矢量。
- GDI 缓存最多保留八对 DC/位图，替换时短暂增加一对；RAII 还原选入对象后释放资源。
- 不引入第三方图标授权，但整体发行许可证仍待项目维护者审核。不同 Windows/GDI+ 版本的离线输出不承诺逐字节相同，差异必须审查。

## 验证及未决事项

离线确定性/拒绝不支持输入、Rust 资源完整性/着色/缓存所有权测试通过；96 DPI 浅深实际像素与 SVG 派生遮罩匹配，20 轮主题/页面循环 GDI 数稳定。150%/200% 实际 GUI、多屏切换、真实高对比度和读屏仍待验收；程序化 DPI 测试不替代这些项目。
