## 记录规范

- 每个实质性开发批次新建 `YYYY-MM-DD-NN-topic.md`，同日从 `01` 递增。
- 记录目标、实际变更、验证命令及结果、限制和下一步。
- 尚未执行、执行失败和验证通过必须明确区分。
- 不复制大量终端输出，不记录真实密钥或本机隐私路径。
- 完成后同步更新本索引和 `STATUS.md`。
- 过去记录保留当时事实；后续补充新记录，不把历史未验证改写成已验证。
