# Token 自动 K/M 单位

日期：2026-10-18

## 目标与实际变更

按用户要求，将图表原有中文万/亿缩写改为自动十进制 K/M。仅修改 `src/ui/history_chart.rs` 和相关文档，不改并行线程的历史页、数据层、控制器或 Cargo 文件。

- 小于 1,000 显示整数；1,000 起显示 K；1,000,000 起显示 M。大于百万继续以 M 表示。
- 最多两位小数，删除末尾零；例如 1,250 → 1.25K、2,500,000 → 2.5M。
- 整数运算截断，不因四舍五入跨单位阈值；实际丢失精度时标 `≈`，例如 999,999 → ≈999.99K。
- 图表各 Token 摘要、趋势标签以及复用该格式函数的请求次数同步统一；明细、文本结果和 CSV 不变。
- 零、未知、缺失覆盖标记保持独立；使用 u128 中间量保证 u64::MAX 安全。
- 补充 K/M 边界、尾零、大数、精度省略及部分覆盖回归断言；更新图表单位说明和 README/UI-DESIGN。
