# 固定底部状态栏

日期：2026-10-18

## 目标与并行边界

将截图中悬空的底部文字整理成简洁常驻状态栏。避免与正在运行的功能开发线程重复：不改 controller、overview、settings、history、logs、theme 的业务接线，不替换已有状态更新调用，不修改依赖/锁文件，不操作用户进程。

## 实际变更

- 新增 `src/ui/status_bar.rs`：在原生 STATIC 上安装 Win32 subclass，保留 HWND、WM_SETTEXT/WM_GETTEXT 及原始完整文本契约，原有操作状态仍从现有入口更新。
- 状态栏左右通栏、贴底固定 56 DIP；浅色浅灰底、深色使用主题 surface，高对比度使用系统 palette；顶部细分隔线，上行强调状态/当前操作，下行说明。文字按当前 DPI 缩放，过长时绘制省略号，`&` 不当快捷键处理。
- 原生 tooltip 保留完整多行文本，SS_NOTIFY 让 STATIC 接收鼠标命中，不增加 Tab stop。tip 缓冲区生命周期跟随工具登记，更新时先切换指针再释放旧内容，销毁时先销毁 tooltip；绘制使用 SaveDC/RestoreDC 和系统画刷，不分配长期 GDI 对象。
- `src/ui/mod.rs` 仅三个接线点：模块声明；原有状态文字不再使用 84/76 DIP 旧位置而改由新模块贴底布局；tabs 创建后附加 subclass。沿用其他页面现有底部预留，不改其布局。
- 新增 `tools/smoke-status-bar-ui.ps1`：仅自动化自有子进程，临时无代理自启配置、无网络请求；检查已有实例并安全拒绝，浅深主题、四页、resize、完整文本、跨进程安全 tooltip 缓冲区、GDI 和截图。未向目标传本进程的 TOOLINFO 指针。
- README、UI-DESIGN、STATUS 和开发索引同步更新。

## 验证

- `cargo check --all-targets --locked --offline`（隔离副本）：通过。
- `cargo test --locked --offline --lib ui::status_bar::tests`：2 项通过，覆盖 CRLF/多行、特殊字符和 96/144/192 DPI 贴底边界。
- `cargo clippy --all-targets --locked --offline -- -D warnings`：通过。
- `cargo build --locked --offline`：Debug 构建通过。
- 编译初期修正 windows-sys 的 `TTTOOLINFOW` 类型名称及未导出 `SS_NOTIFY` 常量，使用公开 SDK 数值 0x0100。
- GUI 浅/深色，DPI192/200%：四个 Tab 的选中项与对应页面可见性通过；每主题两次真实 resize，status 始终可见、三边对齐、高112px；可见 sibling 无重叠。
