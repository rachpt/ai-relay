# 简洁原生外观与统计图表

日期：2026-10-18

## 目标与范围

按用户提供的简洁 Windows 对话框风格，改善原生界面而不引入 WebView、运行时或依赖；增加轻量统计图表。用户要求避开同时运行的功能开发线程。

本批不修改 config/app/history/proxy 业务模块、Cargo 依赖、锁文件或用户数据，不生成发布包、不提交 Git。共享 UI 初始无改动，后续检测到另一线程开始修改 history 页面后即停止写该文件，未回退其变更。

## 实际变更

- `src/ui/theme.rs`：浅色/高对比度恢复原生视觉样式；原先全局禁用主题是经典边框的直接来源。白底与蓝色强调，深色柔和边框、主按钮区分；编辑框 6 DIP 内边距。保留原生 Tab 输入、焦点、读屏语义，只自绘导航外观；高对比度使用系统绘制。
- `src/ui/tabs.rs`：固定且留白一致的四页导航，不显示多余页面框线。
- `src/windows/mod.rs`：正文由 16 改为 14 DIP，标题由 22 改为 20 DIP，仍随 DPI 缩放。
- `src/ui/history_chart.rs`（新增）：独立只读 GDI 展示，四项摘要、最多 12 个返回桶的 Token 柱图、完整/部分/未知请求占比。根据宽度减少桶数，标题说明返回/显示数量；表格/文字保留精确值。区分未查询、查询中、空结果、未知与真实零；部分覆盖标 `*`、缩写标 `≈`，不补未知桶，不声称 Provider 账单。u128 比例计算避免 u64 溢出，SaveDC/RestoreDC 恢复字体与 DC 状态，借用系统画刷。
- `src/ui/mod.rs`：只增加图表模块声明。
- `src/ui/history.rs` 初始展示层改动：高级条件（凭据/协议/结果/三级分组）默认收起，入口 2318，收起保留条件；常用条件缩短标签及提示；按宽度布局、图表固定 200 DIP；调用独立图表；历史操作清 pending 时重绘，避免卡在查询中。**该文件目前混合另一线程新历史功能，不能按整文件 diff 归属本批。**
- `tools/smoke-history-ui.ps1`：测试凭据筛选前展开高级条件。
- `tools/smoke-ui-clarity.ps1`（新增）：PID 检查、单实例安全拒绝、本地 mock、浅深主题重启、真实尺寸 PrintWindow 截图、结果断言及临时数据清理。
- 更新 README、UI 设计、状态和开发索引。

## 并行开发交接边界

另一线程接入时区/趋势/排序/原生表格/别名/存储策略，已在本批工作期间开始修改 `src/ui/history.rs`。本批停止写共享历史页及日志页，不尝试修复其进行中的编译错误。独立模块接口：

```rust
history_chart::draw(item, dpi, font, heading, palette, report.as_deref(), pending)
```

推荐图表至少 696 × 200 DIP。原生 `WM_DRAWITEM` 分派已接入；新增历史按钮超出旧命令范围时，须由功能开发线程扩展分派。高级条件的布局和 pending 重绘需在最终接线保留。图表使用 `TrendPoint.label` 支持小时/日/月标签，不把旧 utc_day 当成所有粒度。
