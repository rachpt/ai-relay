# 2026-10-17-04：反向代理与设置联调

## 目标

从宿主预览推进到真实可测试反向代理，接入设置、配置定位和安全保存。并行任务分别实现代理、持久化、GUI 控制，主线程整合验证。

## 实际变更

- proxy：HTTP/HTTPS 流式转发、SSE、路径前缀、连接池、不重试/不跟随重定向、超时、取消、请求并发限制、有限停止。
- 双向 hop-by-hop 头过滤（含 Connection 动态字段）、上游 Key 三策略、客户端令牌、来源判断和回环健康接口。
- 正向代理、CONNECT、CORS 配置开启明确拒绝启动，相关请求拒绝而非静默转发。
- config：Windows 同目录临时文件与原子保存、最近备份、失败恢复文件保留，拒绝覆盖损坏配置和非普通目标。
- windows/paths：Known Folder LocalAppData 和 current_exe 目录，遵循优先级发现且不依赖 cwd。
- app/controller 与 ui/settings：真实设置控件、有界后台命令/事件、保存/仅启动/停止/加载；首次存储选择、明文秘密二次确认、非回环确认。
- 正常退出等待后台收尾；主线程不执行磁盘、runtime 初始化或 join。
- 新增本地模拟上游、持久化回归和真实 GUI 流程冒烟脚本；Cargo 更新锁文件，新增 ADR 0003。

## 未完成与限制

- 单实例、受限 IPC、自启、DPAPI、目录迁移、完整日志与状态统计尚未实现。
- 保存不直接应用到运行实例，需停止/保存/启动；是开发阶段限制，不删减最终需求。
- 配置自动启动只对回环生效；非回环每次手动确认。
- `--config-dir` 可用；后台/控制命令尚未实现并明确拒绝。
- 当前宿主停止宽限期最多 30 秒，启动初始化限时 30 秒；配置允许的更大值在宿主明确报错。
- 读空闲超时不等于独立慢客户端写超时；尚无实际受信任 HTTPS 成功握手测试、性能或24小时长稳测试。
- GUI 使用合成消息验收按钮，不等于物理托盘点击；多屏 DPI、Explorer 重启仍待人工验证。
- 控制台子系统及正式免运行库发布验收尚未完成。旧脚本与用户数据未修改。
