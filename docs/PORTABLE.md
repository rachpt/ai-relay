# AI Relay 2026.10.18 Windows x64 便携预览

当前为开发预览，不是完成全部验收的正式发行版。

## 使用

1. 解压到当前用户可写目录，双击 `ai-relay.exe`，无需 Node、WebView 或数据库服务。
2. 设置页填写上游和监听，默认仅本机；首次选择软件目录或 Windows LocalAppData。
3. 点击“保存并应用”；“启动已保存配置”不使用未保存草稿。
4. 默认关闭隐藏至托盘，托盘双击恢复、右键退出；外观设置可改为关闭即退出。可记忆窗口位置、大小和最大化。

支持浅色/深色/跟随系统。登录自启在设置中单独确认，默认关闭，创建当前用户 Startup 快捷方式，不安装服务。

## 数据

- 软件目录模式：EXE 同目录 `portable.flag`、`config.toml`、`logs`、历史数据库及身份文件。
- 标准模式：Known Folder LocalAppData 下 `AIRelay`。
- DPAPI 默认把密钥加密写入 `config.toml`，只能由相应 Windows 用户/机器环境解密；拷贝到别处不保证可用。
- 明文模式必须主动确认，配置及备份同样敏感。默认导出清除凭据。
- 历史包含请求IP、模型、接口、时间和不可逆凭据标识，不含正文/原Key；请妥善保护数据目录。
- 统计按已报告usage，不是账单；支持UTC/本地日期和小时/日/月报、凭据别名、排序、策略和清理。CSV可导出当前页或筛选后全量，移除IP和凭据ID但可能含可关联别名；不要随意公开。
- 请求模型仅有界观察不超过64KiB的完整合法JSON上传，其余未知；响应usage缺失、压缩、截断亦不能算零。历史图表K/M为近似展示，明细及CSV保留精确值。
- 目录迁移需先停止代理，保留源数据和日志；目标已有历史时拒绝自动合并。
- 移动程序后自启路径可能失效，需用户确认修复。

## 命令行

`start`、`restart`、`status`、`stop`、`show`、`quit`；支持 `--background` 和 `--config-dir <绝对目录>`。退出码0成功、1未运行/监听、2参数配置错误、3操作失败。
