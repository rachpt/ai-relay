# 页面组织、统计分析与日志交互设计

状态：四原生Tab、日志组合筛选/跟随/分页、分类设置、多维历史时区/月报/排序/别名/全量导出、概览指标和窗口偏好已接入。多屏/读屏/真实高对比度和部分细节仍待验收。下文仍包含目标交互，实际状态以 development/STATUS.md 为准，功能验收以 REQUIREMENTS.md 为准。

## 外观主题（已接入）

浅色、深色、跟随系统，默认跟随；即时预览并正常保存持久化。公开API查询Windows主题，通知变化后更新，高对比度恢复系统颜色。Common Controls v6与DWM增强按支持降级。原生菜单/消息框/滚动条/部分箭头边框不保证统一暗色，须保持可读，不伪称完整WinUI外观。

### 明暗主题与组件精修（2026-10-29，当前外观）

- 依据微软当前 [Windows 配色](https://learn.microsoft.com/en-us/windows/apps/design/style/color)、[几何](https://learn.microsoft.com/en-us/windows/apps/design/style/rounded-corner)与[字体](https://learn.microsoft.com/en-us/windows/apps/design/style/typography)指南，浅色使用 `#F3F3F3` 画布／白色表面，深色使用 `#202020` 画布／`#2B2B2B` 表面；强调色分别为 `#005FB8`／`#60CDFF`。这是应用固定配色，不声称自动采用用户系统强调色或完整 WinUI 实现。
- 主导航采用中性选中表面、24×3 DIP 短强调指示条及被动悬停；焦点跟随原生焦点项，不以选中状态代替焦点。原生命中范围、选择消息、键盘导航及可访问文本不变。展示子类不持有应用 `State` 指针，主题／销毁重入时校验实例与绘制快照；决策见[ADR0019](decisions/0019-fluent-presentation-tokens.md)。
- 次按钮和分段选择改为中性灰状态，主动作保持实心强调，危险操作保留淡红。按钮按下不再位移文字；禁用状态不显示 hover／按压反馈。下拉箭头、switch、表头、行底色和焦点使用同一层级，表头保留原生列宽、排序及命中。
- 页内按钮及闭合下拉圆角从6 DIP收敛为4 DIP，概览／统计卡片统一约8 DIP；Edit及日期框仍保持完整原生矩形边界。统计摘要将表面和边线分开，概览语义色集中在小图标和数据曲线，网格弱于数据线；高对比度保留系统色及虚线／空心标记，不只靠颜色区分信息。
- 状态栏保持40 DIP高度，左右24 DIP与页面内容对齐；主状态用正文色、详情用次文字色，语义色仅用于小图标及其淡底，不把整句状态染色。正文、未知、查询中及完整等价文本语义不变。
- 保留简体中文推荐字体 `Microsoft YaHei UI`、14 DIP正文／20 DIP标题、原生控件、公开DWM API及Win10降级；不新增依赖、动画、浏览器／WinUI运行时或联网字体。高对比度始终优先，矩形输入边界与既有日期／滚动条修复不改。验证结果与限制见[本批记录](development/2026-10-29-01-fluent-theme-polish.md)。以下旧小节保留历史演进，冲突外观以上述本节为准。

### 深色日期框与月历（2026-10-25，当前外观）

日志2224/2225及统计2302/2303保留 `SysDateTimePick32`／`SysMonthCal32` 原生输入、字段选中及可空语义。日期框保留视觉主题并用有界DIB着色；弹出月历单独使用经典原生六色，避免COMCTL32翻月TimerProc绕过着色后留下浅色终帧。经典标题背景兼作星期文字色，采用强调色标题／可读反色标题文字，主体深色；保留原生箭头、七列日期、今天页脚及导航命中。浅色／高对比度恢复默认主题／系统色。

字体安装后重新查询minimum及今天最大宽度；除calendar外同步校正其同线程原生DropDown父容器，避免child扩展后仍被宿主裁掉。最终popup必要时移入显示器工作区，不缩小minimum；不修改时区／日期范围、选日或查询口径。见[ADR0018](decisions/0018-native-dark-calendar-navigation.md)，它仅取代[ADR0016](decisions/0016-dark-native-date-picker.md)的月历着色路线。实际高DPI／多屏／读屏及完整日期矩阵仍待验收，96/144/192字体参数不能替代物理屏幕验收。

### 深色标题菜单（2026-10-19）

标题／系统菜单及文件、代理、视图、帮助子菜单通过公开 `SetMenuItemInfoW(MFT_OWNERDRAW)`、`SetMenuInfo(MIM_BACKGROUND)` 适配深色表面、文字、悬停选中、禁用文字、分隔线、当前页及系统命令图标。原生HMENU仍负责导航、状态和执行，保留 `MIIM_STRING` 文字与 `WM_MENUCHAR` 助记键；不调用未文档化UxTheme暗色函数。菜单字体取系统菜单字体并按DPI度量；浅色／高对比度及正常卸载恢复原项目数据、位图和背景，不回写旧的启禁／radio状态。托盘／表格右键菜单、消息框和月历不在本批范围。详见 [ADR0015](decisions/0015-dark-title-menu.md)。

### 组件精修（2026-10-19，历史外观）

- 浅色采用冷灰画布/白色表面，深色采用蓝灰画布/抬升表面；细边线及次要文字区分内容层级，正文/次要文字与实心主操作具有对比度回归。
- 主导航采用圆角胶囊选中背景；分段选择使用整条中性轨道、选中表面及hover，不再逐项蓝框。原生命中范围、方向键、焦点及兼容消息不变。
- 主按钮实心强调色，次要按钮中性，危险操作淡红；hover/按下/禁用/焦点独立。浅深闭合下拉统一细箭头和边距；switch为实心开启轨道/对比旋钮；表头保留柔和底色/底线，行背景微弱交替，原生行/单元格选择不变。
- Edit保留矩形、不设置region；创建时为既有有边框输入设置真实client edge，展示子类仅在实际非客户区画细边线与聚焦色，严格不覆盖文本、选区、caret或IME。高对比度恢复原生主题/颜色。设计依据见 [ADR0013](decisions/0013-native-control-polish.md)。
- 概览/历史摘要使用更清晰的圆角分块和柔和分隔；底栏融入画布。无新依赖/运行时，代理/配置/确认行为不变。
- Debug及静态CRT Release的96 DPI四页×浅深×两尺寸离屏矩阵通过；物理残影已完成项通过但有遮挡跳过，不代表高DPI/多屏/真实高对比度/IME/读屏验收。详见 [本批记录](development/2026-10-19-01-native-ui-polish.md)。此处记录当时验证，当前主导航／配色／圆角以上方2026-10-29小节为准，日期控件以上方日期小节为准。

### 简洁原生外观优化（2026-10-18）

- 浅色使用白底、蓝色强调色及 Common Controls v6 原生按钮/下拉框，不再全局关闭视觉样式；深色保留公开 API 下的可读回退，高对比度仍交回系统。
- 正文 14 DIP、标题 20 DIP；输入框增加内边距。四个 Tab 保留原生输入和可访问性语义，使用原创 SVG 派生的线性图标、清晰的选中背景（现为中性表面＋短强调指示条）。图标离线生成多 DPI alpha 遮罩并内嵌，运行时有界缓存、随主题着色，不引入 SVG 引擎；高对比度保留原生文字。
- 历史页默认收起凭据、协议、结果和三级分组等高级条件；收起保留条件，不隐式查询或清空。高级入口 ID 2318。
- 独立 `src/ui/history_chart.rs` 绘制请求/输入/输出/总 Token 摘要、最多 12 个返回桶的柱状趋势及完整/部分/未知请求占比；按宽度减少显示桶，未显示桶仍在文字结果中。未知不画零柱，真实零显示 0，部分覆盖带 `*`。图表摘要及标签自动以十进制 K/M 显示（千/百万），最多两位小数并去尾零；采用截断而非跨阈值进位，仅精度省略时带 `≈`，文字明细/CSV 保留精确整数。
- 展示层隔离副本已通过 200% DPI 浅深主题和本地 mock 图表验证；主工作区历史页同时由另一开发线程接入时区、表格等新接口，其最终布局/集成验收不由该隔离结果证明。图表悬停及完整读屏仍待验收。

### 分段选择、开关与暗色控件（2026-10-18）

- 少量固定选项优先直接点击：统计来源、日期快捷项、时区、趋势粒度、结果视图、导出范围以及外观主题改为原生 Tab 支撑的分段选择（单选语义），保留方向键、焦点与可访问性。协议、接口、分组和排序等长选项继续使用下拉框。
- 日期输入仅在“自定义”显示，重置后恢复隐藏；已有历史结果时切换时区/趋势自动后台重查，首次打开不自动查询。表单条件仍通过明确“查询/应用”提交，收起高级筛选不丢值。
- 原生布尔 checkbox 在浅/深色绘制为开关，保留 BM_GET/SETCHECK、Space、点击和确认流程；不是将风险操作改成立即生效。高对比度使用原生系统绘制。
- 深色列表背景、文字、选中行与表头统一使用应用配色；剩余下拉框闭合内容及箭头不再使用白底。系统菜单和对话框仍可能是系统浅色，未使用未文档化暗色 API。
- 主要操作添加简单符号图标并保留中文标签，分段选择圆角/细边框，表格减少网格线；状态栏使用运行三角、停止方块、忙碌三点、错误叹号图标，并以文字保留语义；高对比度恢复系统文本色。颜色不替代文字语义。
- 统计结果视图独占一行，排序与导出范围位于上一行；修正 HTTP 标签与 Provider 输入重叠，高级筛选与操作行增加留白。当前显示器200% DPI冒烟通过，物理读屏/高对比度/多屏仍待验收。

### 柔和圆角（2026-10-18）

按钮、闭合下拉框初期采用约6 DIP小圆角，2026-10-29收敛为4 DIP；卡片/图表统一约8 DIP，分段选择和switch沿用相应圆角。不裁剪表格、任何Edit、日期框、原生菜单及弹出月历。浅深按钮与深色闭合下拉使用一致圆角表面；单行、多行及密码Edit及日期框统一保留完整原生边框，不再通过region裁掉边角，也不覆盖客户区、输入光标或IME。日期框的原生矩形边线无法仅靠圆角裁剪连接成圆弧，2026-10-25起取消这层裁剪，避免浅深主题四角断边。高对比度清除圆角区域，恢复系统边界。控件值、焦点、键盘和原生弹出选择语义不变。

### 日历日期选择（2026-10-18）

统计自定义日期使用 `SysDateTimePick32`，原生月历下拉、键盘分段编辑及可空边界；支持1970–9999的有效日期与闰日。取消勾选某一侧表示该侧不限，开始含/结束不含及UTC/Local历史日边界语义不变。只在自定义显示，不增加查询或自动保存；选好后按查询应用。

初期闭合未聚焦态配合暗色；曾尝试禁用月历视觉主题，但200% DPI出现布局／绘制裁切，因而退回原生浅色。该历史降级曾由2026-10-20栅格着色取代；2026-10-25进一步确认翻月TimerProc绕过着色，改为经典原生深色颜色，并同时修复被独立DropDown父容器裁切的根因，外观与验收以上节为准。

本轮不增加全年热力图：当前趋势可为小时/日/月、返回桶有界；不能直接把缺记录/未知用量画成零消耗热力格。后续若增加应独立定义每日覆盖、数据范围及交互，不挤占当前趋势和明细。

### 紧凑页面与日志日期（2026-10-18）

- 默认800×680 DIP，最小800×560 DIP；固定顶部44 DIP导航与底部40 DIP单行状态栏，中间原生裁剪滚动宿主，四页独立offset，轮滚/拖动/键盘可达，焦点自动揭示。跨DPI换算四页offset，过期焦点消息不能滚动新页；保留控件、草稿与内部日志选区。顶部左侧为客户端☰菜单、应用图标与 `AI Relay` 名称，右侧为四个带SVG派生线性图标的Tab，中性选中表面搭配短强调指示条；Tab紧贴标题栏，不保留额外空白行。窗口小图标/任务栏保留应用图标，不用☰占用 caption 图标槽。
- 页面布局只更新控件几何、不立即重绘；滚动宿主在最终视口位置统一移动并异步失效背景、可见子控件及非客户区边框，避免“文档坐标→视口坐标”的中间帧残影和重复绘制。页面布局按当前尺寸/DPI缓存，切回已定位页面只刷新滚动元数据；统计子视图可见集合变化时重建文档坐标并重新应用当前offset，日志预布局单独使用848 DIP最小高度。显示/隐藏与几何移动使用批量窗口事务；缩放、分类及切页都在最终位置排队完整重绘，不依赖拖动结束通知。
- 设置分类2039改为六项常驻原生分段导航，保存/启动/停止/加载按当前分类末尾+24 DIP布局。应用按钮蓝色，删除/清空柔和红色，仍保留确认流程。
- 日志2224/2225改原生可空DateTime picker，本地开始/结束日期均含整日，按历史时区规则解析，GUI不再输入epoch；逻辑解析器的epoch支持保留。类别改三项分段。
- Edit/ListView和页面宿主非客户区滚动条采用公开几何API暗色覆绘，原生位置、拖动、选区和复制语义保留；深色条带融入页面背景，仅绘制约6 DIP圆角胶囊滑块，不再显示粗条和箭头；浅色/高对比度卸载覆绘。系统下拉菜单/拖动动画可能短暂保留系统色，不伪称彻底替换原生组件。

## 1. 主窗口

客户端顶部左侧“☰”单击打开文件/代理/视图/帮助；F10和Alt+M走相同入口，Alt+Space保留系统菜单。采用原生系统菜单插入应用分组，视图与启动/停止/重启项使用轻量符号前缀，不自绘完整非客户区；窗口小/大图标、任务栏/Alt+Tab保留产品图标。菜单状态随后台可用性更新，执行时再次校验；复用原导入/导出/启动/退出确认和生命周期。标题／系统菜单深色适配见上节，浅色／高对比度保留OS配色；标准窗口缩放和关闭按钮不变。

设置示例采用的分类、分组留白、滚动内容和明确动作区符合现有路线；保留六项分段导航与内容末尾操作行，暂不另开独立设置窗口或强加“确定/取消”语义。

采用 Win32 原生 Tab 控件，固定四页：**概览、统计分析、实时日志、设置**。客户端头部左侧显示应用图标与 `AI Relay` 名称，右侧为四个Tab；窗口标题及底部状态栏常驻，显示监听状态、当前操作和统计/日志持久化异常提示，不显示密钥。

- 页面尾部统一距固定状态栏16 DIP，不再重复预留旧状态区：概览、统计各子视图和日志在大窗口/滚到底时一致；设置按当前分类实际末尾确定滚动范围，短表单保留自然空白但不生成空白滚动尾。滚动条显隐先确定实际客户区宽度，再布局并更新宽度缓存；暗色页面宿主在无条时保持主题，恢复条带不闪回白色。详见[底部留白修复记录](development/2026-10-19-02-status-bar-spacing.md)。
- 底部状态栏固定贴底，高 40 DIP、左右通栏，细分隔线区分正文；浅/深色随主题，优先高对比度系统色。单行显示：状态图标 + 状态/当前操作 + 详细说明。长文字以省略号显示，原生 STATIC 的完整文本不截断；tooltip 维护完整多行内容，悬停显示稳定性仍待验收。控件不进入 Tab 顺序，不改变原有状态更新接口。
- 切换页面保留筛选、滚动、选区及未保存设置；不触发代理重启或隐式保存。
- 页外控件隐藏且移出键盘导航；支持 Ctrl+Tab、正常焦点顺序和屏幕阅读器。
- 100%/150%/200% DPI 测试，较小窗口使用局部滚动，不截断按钮。
- 隐藏窗口或不可见页面停止不必要绘制；采集不依赖当前打开哪一页。
- 后台查询和页面加载可取消，返回结果须匹配当前筛选版本，不能让慢旧查询覆盖新结果。

## 2. 概览

只放运行信息和常用动作，不放完整配置表单或全量统计明细。

已实现仪表盘：顶部运行信息及一排五个原生操作按钮；四张圆角、中性大号卡片显示累计请求/错误次数/活动请求/下载累计，非零错误图标保留语义色，副文案保留隧道、入站和上传。下方两张响应窗口高度的大图：请求与错误次/s、上传与下载B/s，带实际时间轴与网格。图表头部两行紧凑布局：标题右侧显示“区间均值 · 单位”，下一行按真实字体文字宽度相邻排列“短线/点标记＋名称＋最新速率”，不再将图例各分配半行或单列速率摘要。正常绘图区顶部为68 DIP，有当前未知原因时保留独立提示并用88 DIP；长标签有界省略，精确值仍在原生等价文本。新绘制模块 `overview_dashboard.rs`，原生控件元数据保留精确累计及最新速率等价文字。

采样使用代理实际uptime及累计计数差，约每秒一次，最多120点且只保留120秒；首次、超过5秒缺口、计数饱和保持未知、断线，不按样本索引伪造满幅两分钟历史，不从请求数减错误数推成功率。页面/窗口隐藏时仍收快照但不重写控件或绘图。较矮窗口通过页面滚动到达完整内容；dashboard自身不足绘图最小尺寸时降级精确文字指标。当前最小外框下dashboard高于视口，不能用父视口裁掉后的单张图冒充完整图表验收。浅/深色及200% DPI截图通过，完整读屏/多屏仍待验收。

- 状态、实际监听、上游显示名、运行时长、活动连接。
- 请求/错误、当前会话已报告 Token 摘要及未知覆盖提示。
- 启动、停止、重启、复制 Base URL、打开数据目录；目录初始化且后台空闲时启用，点击显示处理中，后台返回真实Shell接受/失败结果，不把接受请求当作Explorer窗口已显示。
- 统计/日志异常可跳转对应页；错误不以弹窗风暴阻塞转发。

## 3. 统计分析

### 布局

```text
[时间范围] [时区] [IP] [模型] [客户端凭据] [上游凭据]
[Provider] [协议/接口] [结果] [查询] [重置筛选]
[请求数] [已报告输入/输出/总Token] [未知/截断/落盘丢失]
[按小时/天/月趋势图：请求数或Token，可切换序列]
[分组维度：日期/IP/模型/凭据/Provider/接口，最多三级]
[可排序分页汇总表，含完整度列]
[请求明细/汇总表排序] [本页/筛选全量CSV] [凭据别名/策略/清理]
```

- 时间默认跟随用户系统本地时区，首次打开与重置筛选均选中本地，保留显式UTC选项；日期快捷项、自定义范围、明细、分组、趋势使用同一所选时区，存储UTC。日期快捷项：今天、昨天、近7天、近30天、自定义；按所选时区解释日边界。
- 筛选条件组合使用 AND，同一维度多选使用 OR；默认展示全部，不默认剔除错误或未知用量。
- 两类凭据分开：客户端提供的凭据与实际发送的上游凭据；只显示别名/本地不可逆标识，缺失标记无凭据，不显示原Key片段。
- 模型分请求模型/响应模型。请求模型提取需有界，不能整体缓存上传体；无法安全提取则未知。实际Provider来自配置身份，不从协议推断。
- 表格显示请求数、成功/失败/取消、输入/输出/总量、缓存/推理、usage已报告比例、截断及采集缺口。
- 请求明细/分组汇总的原生ListView支持单元格复制：点击或右键定位，Ctrl+C或原生“复制单元格”菜单复制完整格文本；左右按视觉列顺序导航并揭示，原生上下/Page/Home/End保持行导航。活跃格双层边框兼容浅深及系统高对比度颜色，原生行选择不变。右键键盘入口支持Shift+F10/菜单键。无选择、空白、隐藏/禁用或表格重建后不写剪贴板；空字符串是有效格值。单格上限1,048,576个UTF-16单元，超限/非法编码拒绝而非截断。复制只含该格，不额外匿名化IP/别名/HMAC ID，不改变CSV脱敏规则。
- 暗色请求明细／汇总Report列表局部使用公开COMPOSITED样式，原生滚动与暗色条带在短暂持有的同一window DC中完成后呈现；NC更新region排除横纵条／交角但保留原生边框。无内部禁绘或range替换，浅色／高对比度只恢复自有样式位，纯合成位变化不清单元格复制目标。48个按住／滚动内部物理轨道样本通过，但最终Release统计页完整GUI仍因Tab消息超时未验收，见[记录](development/2026-10-25-03-dark-report-scroll.md)与[ADR0017](decisions/0017-dark-report-scroll-presentation.md)。
- 请求明细仅含必要元数据：时间、来源IP、凭据别名、模型、接口类别、状态、耗时和用量完整度，不含正文/认证头/原始查询参数。
- 图表使用轻量原生绘制（GDI等），不引入WebView。有坐标、单位、图例、悬停值及表格等价信息，不能只靠颜色。
- 未知不是0；无数据、未知、加载中、查询失败分开显示，禁止画假零线掩盖缺失数据。
- 图表采样点和表格页大小有上限；建议最多366点、每页100行，长区间以更粗粒度聚合。
- 导出在后台进行，仅输出当前筛选范围；明确脱敏/隐私提示，不能无提示导出IP或可关联凭据身份。
- 当前会话和历史数据源明确区分，不把历史未实现时的空白解释为历史0消耗。

### 数据完整性

采用请求级元数据及恰好一次终态记录，重复最终SSE事件不能重复计数。本地拒绝、失败和取消分别计数，与目前仅上游观察的口径不同，实施时更新回归测试。报表展示记录丢失、未知usage与未完成请求；不把“响应成功”直接当作“用量完整”。

历史存储采用内嵌SQLite（bundled rusqlite），版本化元数据；查询/导出固定只读actor与写入worker隔离，路线见ADR0007/0008。大范围聚合可能十余秒，界面非阻塞显示pending，读取预算60秒。持久化必须走有界后台队列，满队列不阻塞网络，丢失可见。统计保留期/清理与日志分别管理。

## 4. 实时日志

### 日志来源与模式

- **实时视图**：同一个日志后台先脱敏再分发内存订阅和文件写入；允许短暂尚未落盘，必须显示落盘异常，不伪称已写入。
- **文件视图**：在软件内选择本应用当前/历史日志文件，加载有界尾部并分页向前查看；支持跟随当前文件追加，轮转、截断、删除时重定位或明确停止跟随。
- 文件读取共享写入，不长时间锁文件；不一次读完整大文件，不在UI线程等待磁盘。
- 默认只枚举选定数据目录下本应用管理的日志，不开放任意文件删除入口。

### 工具栏和列表

- 日志内容继续使用原生只读多行Edit，不转换为自绘表格。下方新增原生可聚焦高度调整条：默认240 DIP、120–720 DIP有界拖拽；方向键每次24 DIP、Home恢复240、拖动Escape回滚。高度只在本次运行内保留；窗口缩放不自动分走用户选定高度，超出可见页通过页面滚动到达，下方操作随高度移动。日志页虚拟高度按实际查看区＋下方固定内容动态计算，末尾仍保留16 DIP。
- 日志正文Edit2200横／纵滚动条分别按原生内容范围决定显隐，内容不溢出不显示禁用条；正文、尺寸及字体变化后重新探测，隐藏轴不复用旧range。尺寸更新合并到布局事务后的消息；双轴从无条开始逐轴测量，避免条带互相挤占形成假溢出。保留选区／有效滚动位置，捕获期间不改显隐，释放后更新；浅深／高对比度使用相同策略，其他输入框与表格不改。
- 暗色滚动条不再调用原生非客户区鼠标modal tracking：拇指/轨道/端部输入由公开捕获/定时重复适配，驱动原生Edit、Report ListView或页面宿主的完整32位位置，不合成16位thumb值或改range/page。hover/按下仍是窄胶囊；浅色/高对比度恢复原生。文本/选区/caret/键盘/滚轮及可访问性结构不替换，详见[ADR0014](decisions/0014-scrollbar-tracking-log-resize.md)。
- 共享viewport活动页改变前取消旧暗色滚动跟踪并释放自有capture/timer/hook，同页刷新不取消拖拽；日志grip键盘调整结束后异步揭示当前焦点，消费时重查parent/focus/visible，鼠标拖拽不触发自动揭示。四项review修复、验证失败及剩余白条取证限制见[08记录](development/2026-10-19-08-review-interaction-fixes.md)。
- 输入框及滚动条在geometry/font/style/DPI/no-redraw事务内只排队非客户区重绘，保护频繁高度拖动不写中间坐标；实际补画仍在原生paint之后，借用打印DC受RAII保护。
- 本批Debug96 DPI有33张有效按住阶段物理条带截图，白色大条采样像素0；Release交互通过但物理截图被Explorer遮挡，没有用离屏图替代。不能代表连续视频、硬件指针、高DPI/多屏/读屏验收，详见[记录](development/2026-10-19-04-log-resize-dark-scrollbars.md)。
- 时间范围、日志级别、请求/运行类别、状态码/错误、文本搜索。实时/文件视图显示系统本地时间及UTC偏移；日期范围按本地整日计算，兼容23/25小时的DST日期。底层JSONL保留UTC epoch，文件展示副本增加`timestamp_local`，复制该行仍为JSON但包含展示字段，不改写原文件；实时展示保留原始epoch/事件文本。
- 自动滚动开关、暂停显示、恢复、复制选中、打开日志目录、清空视图、管理日志。
- 列表：时间、级别、请求ID、IP、方法、脱敏路径/接口、目标显示名、状态、首字节/总耗时、摘要。
- 暂停仅暂停显示，不暂停转发和落盘；恢复时只补有界缓存，缺口标记，不无上限积攒。
- 选择文本或向上滚动时不强拉到底；用户可显式恢复自动跟随。
- 关闭文件日志不等于关闭实时视图，界面分别表达；关闭访问日志不影响运行错误日志。
- 日志和统计通过本地请求ID关联，不通过完整Key关联。

### 设置与清理

在设置页提供日志设置快捷入口：文件日志开关、访问日志开关、级别、单文件上限、保留数量/天数、GUI缓存条数，以及实际目录/当前占用。沿用需求默认5MiB、共3文件、GUI1000条；保留天数建议7天。启用多个清理限制时取先达到的限制。

- **清空视图**仅影响显示，不删除文件或统计。
- **删除历史日志**先展示文件数和体积，确认后由日志worker删除关闭的应用日志。
- **清空全部应用日志**再次确认；worker串行刷新/切换或重新打开当前文件，不能UI直接删正在写的句柄。清理后允许新日志继续产生，不宣称目录永远空。
- 删除失败逐项报告，部分成功明确显示，不能返回虚假全部成功。
- 不删除数据库、config、secrets、用户其他文件或旧版根目录日志。不跟随重解析点清理目录外文件。
- 清理可以影响当前文件视图，需清楚提示并重置文件游标；不可导致转发暂停或崩溃。
- 磁盘满/权限失败时保留有界实时错误提示，不递归通过同一失败日志路径记录错误。

## 5. 设置

使用页内分类导航：上游与认证、监听与访问、代理模式、启动与托盘、配置与密钥、日志、统计存储。

主页面不同时铺开所有分类。敏感值遮挡；未实现项说明原因，不用可点击空按钮模拟功能。保留待保存修改提示，退出前可选择保存、放弃或取消，不能仅切换Tab就丢输入。

## 6. 建议实施顺序

1. 原生Tab与页面生命周期，保持已有设置、代理、单实例和统计回归。
2. 有界日志后台、脱敏轮转、实时/文件视图、设置和安全清理。
3. 多维元数据采集和历史存储，再接筛选、汇总表、趋势图、明细与导出。
4. UI高日志量、长时间窗口隐藏、大文件、清理竞争、DPI和键盘可访问性验证。

## 7. 验收补充

- Tab切换不丢输入/筛选、不触发监听变化；后台事件更新正确页面。
- 使用本地mock对同IP多模型、多凭据、多接口及跨日期边界校验组合筛选和汇总；未知不补0，分页/图表/导出相同口径。
- 用测试注入的时钟覆盖UTC/本地日期边界和夏令时，不修改系统时钟。
- 日志中虚构Key/Token/query/body测试串不得泄漏；长行、坏UTF8、大文件均有界处理。
- 实时追加、暂停恢复、轮转、文件截断和清理并发时无UI卡死；清空视图不删文件，删除历史不影响当前写入，清理不越界。
- 队列满、磁盘满或权限失败明确显示丢失/异常，转发保持独立。
